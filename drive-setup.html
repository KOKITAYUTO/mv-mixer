Google Drive同期の設定

Google Cloud登録前でも「共有ファイルを書き出す」で素材と設定を .mvm にまとめられます。手動でDriveにアップロードし、別PCでダウンロードして「共有ファイルを読み込む」ことができます。

直接保存・読み込みのコードは準備済みですが、実際のGoogleアカウントでの接続・転送はまだ未検証です。以下のGoogle設定完了後、まず小さいテスト素材で確認してください。

1. Google Cloudを設定する（管理者が最初に1回）

  1. Google Cloud Consoleを開き、制作管理用のGoogleアカウントでプロジェクトを作成します。例：I-Roid MV Mixer。
  2. 「APIとサービス → ライブラリ」で Google Drive API と Google Picker API を有効にします。
  3. 「Google Auth Platform」（またはOAuth同意画面）でアプリ名、サポートメール、連絡先を登録します。組織外のメンバーも使う場合は外部ユーザー向けにし、テスト中は制作メンバーをテストユーザーへ登録します。画面の名称はGoogle側の更新で変わることがあります。
  4. データアクセスに https://www.googleapis.com/auth/drive.file を追加します。Drive全体へのアクセスではなく、このアプリで作成・選択したファイルを扱う権限です。
  5. 「クライアント」で種類を「ウェブアプリケーション」にしてOAuthクライアントIDを作成します。「承認済みのJavaScript生成元」には、実際に使うサイトのオリジンを登録します。ローカル確認なら http://127.0.0.1:8765。公開後は実際の https://ホスト名 を追加します。パスや末尾のスラッシュは付けません。今回のポップアップ方式でクライアントシークレットを使う必要はありません。
  6. 「APIとサービス → 認証情報」でAPIキーを作成します。アプリケーション制限は「ウェブサイト」にし、http://127.0.0.1:8765/*、実際の公開サイトの https://ホスト名/*、Picker用の https://docs.google.com/* を登録します。API制限はGoogle Picker APIにします。
  7. プロジェクトの概要で プロジェクト番号（数字） を確認します。文字列のプロジェクトIDとは異なります。

2. プレイヤーへ登録する

  1. file://で直接開かず、ローカルサーバーまたは公開HTTPS URLからプレイヤーを開きます。
  2. 「Google Drive / 共同制作 → Google接続の初期設定」に、共有先フォルダーID・OAuthクライアントID・APIキー・プロジェクト番号を入力します。共有先フォルダーIDはDriveのフォルダーURLの /folders/ の後ろの文字列です。これはブラウザー用の公開設定値です。クライアントシークレットやアクセストークンは入力しないでください。
  3. 「接続を準備」を押し、準備完了後に「Googleに接続」を押します。Googleの画面で、I&Roidを編集できるアカウントを選んで許可します。
  4. 「保存先フォルダーを選択」で、I&Roid内の 00_共有プロジェクト（素材と設定） を選択します。誤保存を防ぐため、このフォルダー以外は受け付けません。

3. 共同制作の流れ

  1. 最初の担当者が映像・WAV・カーブを登録し、「Driveへ新しい版を保存」を押します。全3テーマの素材と設定が1つの .mvm になります。
  2. 別の担当者は同じGoogle Cloudアプリの設定値を入力して接続し、「Driveから読み込み」で保存された版を選びます。Google Pickerでファイルを選ぶことにより、その担当者もアプリへのアクセス許可を与えます。
  3. 読み込むと、現在の3テーマを置き換えます。確認画面で承認する前に、未保存の変更を共有ファイルとして書き出してください。
  4. 編集後は再び新しい版として保存します。同じファイルを上書きせず、日付と識別子を付けた別ファイルを作ります。採用版を制作ガイドへ記録してください。
  5. 会場PCでは採用版を読み込み、「この端末に保存」してから再生します。本番中に他の人の更新が勝手に反映されることはありません。

保存されるもの・されないもの

保存対象：3テーマの映像と音源本体、映像モード、ステムの役割・音量・個別カーブ、マスター音量、フェード設定、ミックス位置、ループ設定、選択中テーマ。

対象外：Google接続用トークン、MIDI機器の割り当て、Wwise試聴設定、再生中の位置、Googleドキュメントの内容。Google接続トークンはメモリーだけに保持し、切断・ページ再読み込みで破棄します。OAuth ID等の公開設定値は端末に保存されます。

容量・競合・接続切れ

1ファイル最大2GB。各保存版に素材全体を含むため、Driveの容量を消費します。古い版は採用版とバックアップを確認してからDrive上で整理してください。多数のWAVは読み込み時のメモリーも使用します。

この機能は明示的な保存・読み込みによる版の共有です。Googleドキュメントのような同時編集・自動マージではありません。同時に編集した場合は別々の版になり、採用版は制作メンバーが決めます。

接続期限切れは再接続してください。転送エラーは自動再送しません。特に完了応答が失われた場合はDriveにファイルができている可能性があるため、フォルダーを確認してから再保存してください。途中からの自動転送再開は実装していません。

共有権限

フォルダーの閲覧・編集権限はGoogle Driveで設定します。プレイヤーは共有権限を変更しません。制作メンバーのみを編集者に設定する場合は、所有者がDriveで変更してください。
